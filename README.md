# Bois Simulation

A simple boids simulation implemented in Python using Pygame. It models flocking behavior by simulating fish that follow three basic rules:
- Separation: Avoid getting too close to nearby fish.
- Alignment: Align direction with nearby fish.
- Cohesion: Move toward the center of nearby fish.

## Requirements

```
pip install -r requirement.txt
```

## Run

```
python src/main.py
```
